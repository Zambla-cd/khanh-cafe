# Khánh Cafe

## Giới thiệu
Khánh Cafe là website giới thiệu và quảng bá quán cà phê, được xây dựng nhằm mang đến trải nghiệm thuận tiện cho khách hàng khi tìm hiểu về quán và thực đơn.

## Chức năng chính
- Trang chủ: Giới thiệu tổng quan về Khánh Cafe.
- Thực đơn: Hiển thị các loại đồ uống và sản phẩm Best Seller.
- Không gian: Giới thiệu không gian quán.
- Giới thiệu: Cung cấp thông tin về quán.
- Đăng nhập - Đăng ký: Hỗ trợ tài khoản khách hàng.
- Hỗ trợ: Tích hợp chatbot AI tư vấn khách hàng.

## Công nghệ sử dụng
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Ollama (Qwen 2.5 3B)

## Chạy dự án
1. Cài đặt Node.js và Ollama.
2. Cài đặt model `qwen2.5:3b` bằng Ollama.
3. Mở thư mục backend.
4. Chạy lệnh `npm install`.
5. Khởi động server bằng lệnh `node server.js`.
6. Mở website bằng Live Server.
